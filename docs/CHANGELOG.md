# Публичный журнал

## 2026-11-10 — OpenCode Console и все окна Claude Code

- Claude Code: usage-endpoint Anthropic отдаёт окна в расширяемом массиве
  `limits[]`. Коллектор читал только плоские ключи `five_hour`/`seven_day`, поэтому
  новый недельный лимит по модели не появлялся; passive-заголовки знают лишь
  сессию и неделю и его не передают. Теперь `limits[]` разбирается обобщённо,
  неизвестный вид сохраняется как своё окно, а окна обоих источников
  объединяются по id: окно, о котором знает только нативный ответ, больше не
  исчезает при passive-наблюдении. Нативный опрос идёт с интервалом подписки
  вместо ожидания простоя.
- Новый провайдер `opencode` читает рабочее пространство OpenCode Console
  (pay-as-you-go): баланс, счётчики по моделям, бюджеты и метры Go. Кред — активная
  интеграция `opencode` локального сервиса OpenCode, как у Ollama и Kimi; origin
  Console зашит в код, сессия не обновляется. Остатка бесплатных моделей Console
  не публикует, поэтому bridge-плагин теперь записывает отказ 429 с моментом
  сброса.
- Схема v1 расширена только optional-полями: `label`, `limited`, `observed_at`,
  `counters` и `metric: counter`. Старые клиенты их игнорируют. Мод показывает
  счётчики значениями, а не выдуманным процентом, помечает неограниченное окно
  и выводит баланс строки pay-as-you-go. Окна подписки сохраняют порядок и
  новые поля при записи в приватное хранилище.
- Деплой: generic-скрипт `quota-hub/scripts/deploy.sh` тянет исходники, собирает
  бинарник, перезапускает сервис и откатывается, если readiness не ответил.
  Машина сбора получает Go локально; скрипт не содержит ни адреса, ни секрета.
