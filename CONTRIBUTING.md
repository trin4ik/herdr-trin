# Разработка

Один источник правды: исходники в этой монорепе, без `github-release/` с ручным
дублированием. Root AGENTS.md на персональной установке может оставаться локальным;
публичные инструкции для модов и сервиса лежат в их AGENTS.md.

- При изменениях обновлять `docs/CHANGELOG.md`; в персональной рабочей папке —
  также локальный корневой `CHANGELOG.md`, если этого требуют местные инструкции.
- Не коммитить credentials, `.env`, runtime config/state, историю подписок,
  личные ID/пути/адреса, рабочие снимки и логи. Использовать синтетические fixtures.
- Не опрашивать реальные подписки из тестов, не запускать refresh/генерации,
  не устанавливать плагины и не перезапускать production-сервисы без разрешения.
- Не менять generated GPUI types. Использовать API установленного Herdr.
- Сначала события; polling только при отсутствии подтверждённого event-контракта.
- Перед публикацией выполнить проверки из обоих README и security checklist.
- Все команды Git — без force-add личных материалов. Публикация не автоматическая.
- Не добавлять зависимости от персональных task runners/обёрток CLI. Новые
  внешние команды должны быть общедоступны и описаны в README; portability gate
  проверять вместе с offline-тестами. Выполненные task-промпты/временные снимки
  не хранить рядом с рабочими исходниками.
