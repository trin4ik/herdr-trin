# Deliva brand asset

`deleeva-mark-dark.svg` и его PNG-растеризация — фирменный знак владельца
персонального layout, не новый MIT-ассет. Геометрия и цвета не менялись.
Владелец подтвердил право распространения вместе с этим layout 2026-11-06.
Неизменённые SVG/PNG разрешено передавать в составе layout с этим уведомлением.
Общая MIT-лицензия исходников не распространяется на знак; права на торговую
марку и использование её для несвязанных продуктов не предоставляются.

Runtime использует реальную PNG-копию
`assets/trin-brand/deleeva-mark-dark.png` из-за sandbox внешних symlink-модов.
Установщик ставит копию из этой директории. SVG остаётся каноническим источником;
`image()` сохраняет полную палитру, `svg()` перекрасил бы её цветом темы.
